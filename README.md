# 💌 3D Wedding Envelope Animation

A beautiful, interactive 3D wedding invitation envelope that opens on hover. Built with pure HTML and CSS.

## 🎉 Features

- ✨ **Full 3D Animation** - Uses CSS 3D transforms for realistic envelope opening
- 💫 **Smooth Hover Effects** - Flap rotates and letter slides out
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
- 🎨 **Elegant Styling** - Romantic color palette and typography
- ⚡ **No JavaScript** - Pure CSS animations
- 🚀 **Fast Loading** - Lightweight and optimized

## 🎯 How It Works

1. **Hover** over the envelope
2. Watch the **flap open** with 3D rotation (rotateX)
3. See the **invitation letter slide out**
4. Smooth, elegant animations throughout

## 📝 Customization

Edit `index.html` to change:
- Wedding couple names
- Date and time
- Venue details
- RSVP information

Edit `style.css` to change:
- Colors (primary colors: `#d4a574`, `#8b6f47`, `#a37e6a`)
- Font styles
- Animation speed (change `0.8s` to faster/slower)
- Envelope size

## 🔧 Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - 3D transforms, animations, gradients
- **Google Fonts** - Dancing Script & Georgia fonts
